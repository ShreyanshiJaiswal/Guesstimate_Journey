# Guesstimate 19: Estimate the Number of Cabs in Delhi

## Clarifying Questions
- Are we considering cars, bikes, autos, or all types of cabs?
- Are both EV and petrol/diesel vehicles included?
- Are we considering Delhi only or the entire Delhi NCR?
- Are we considering app-based cabs such as Ola and Uber or traditional independent cabs as well?
- Are we estimating the number of cabs operating on a typical weekday?

## Final Question
Estimate the number of **app-based car cabs operating in Delhi on a typical weekday**, including both EV and petrol/diesel cabs, and excluding autos, bike taxis, traditional independent cabs, and carpooling services.

## Solution

### 1. Delhi Population

Assume Delhi population = **20 million**

### 2. Daily Travelers

Assume **70%** of the population travels on a typical weekday.

**20M × 70% = 14M daily travelers**

### 3. Daily App-Based Cab Users

Assume **15%** of daily travelers use app-based cabs.

**14M × 15% = 2.1M cab users/day**

### 4. Daily Cab Trips

Assume each cab user makes an average of **2 cab trips per day**.

**2.1M × 2 = 4.2M cab trips/day**

### 5. Trips Completed per Cab

Assume one app-based cab completes approximately **12 trips per day**.

### 6. Number of Active Cabs

**Number of Cabs = Daily Cab Trips ÷ Trips per Cab per Day**

**4.2M ÷ 12 = 0.35M**

**= 350,000 cabs**

## Key Logic

**Delhi Population → Daily Travelers → App-Based Cab Users → Daily Cab Trips → Trips per Cab → Number of Active Cabs**

## Final Estimate

**≈ 350,000 active app-based car cabs operate in Delhi on a typical weekday.**
